# Concepts
* [Add a Feature](add-a-feature.md) - The end-to-end procedure for adding a vertical slice across every layer.
* [Build and Test](build-and-test.md) - Install packages, generate code, analyze, format-check and run the headless tests with coverage.
* [Format Code](format-code.md) - Format Dart sources with dart format and check without changing files.
* [Generate Coverage](generate-coverage.md) - Produce an lcov report from the headless tests and fail below the 80% line-coverage threshold.
* [Run E2E Tests](run-e2e-tests.md) - Run the device e2e suite on a simulator against the mock server, with the dev flavor.
* [Run the App](run-the-app.md) - Start the mock backend and run a flavor of the app with its env file.
