How the stack is built, tested, released and developed locally.

# Concepts
* [CI Pipeline](ci-pipeline.md) - GitHub Actions checks every pull request; Dependabot opens dependency PRs; an optional pre-commit hook runs the same format and bundle checks locally.
* [Infrastructure](infrastructure.md) - Build signing, release channels and deployment of the app; flavors exist, signing and release do not.
* [Local Development Environment](local-development-environment.md) - What a developer needs: Flutter/Dart SDK, a simulator, and the mock server.
* [Test Architecture](test-architecture.md) - The test tiers, where each lives, what it proves and how to run it.
