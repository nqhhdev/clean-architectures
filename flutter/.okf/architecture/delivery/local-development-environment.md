# Local Development Environment

* Flutter 3.38.x / Dart 3.10.x (the versions this starter was built with; `environment: sdk: ^3.10.8`).
* Xcode and an iOS simulator for e2e on iOS; an Android emulator for Android (not exercised yet).
* `dart run tool/mock_server.dart` for a backend.
* Commands: [Build and Test](../../workflows/engineering/build-and-test.md), [Run the App](../../workflows/engineering/run-the-app.md).
