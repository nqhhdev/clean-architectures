# Flutter

Toolkit and test runner (`flutter test`, `flutter analyze`). Built with Flutter 3.38.9 / Dart 3.10.8. Any Flutter import is allowed only in `ui/`, `config/` and the root files;
lower layers follow the allowlist in [Layered Architecture](../../architecture/cross-cutting/layered-architecture.md). Guide followed: [ADR 0001](../../adr/0001-flutter-app-architecture-layers.md).
